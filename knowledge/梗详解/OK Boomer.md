# OK Boomer：出处、语境与延伸

检索别名：OK Boomer。

## 常见含义与语境

- 对代际说教的简短回击；使用时很容易把讨论变成人身代际攻击；2019 年英语社交平台走红（原索引：网络梗年代图鉴.md，英语互联网与跨平台格式（2011—2026））

## 出处与传播证据

### OK Boomer：参考材料《OK boomer》

OK Boomer（本意为「好啦，嬰兒潮老人」，亦可延伸解釋為「好了，老人家」），是2019年广泛流行于年轻群体的口头禅和网络模因，用来嫌弃或嘲讽婴儿潮一代（Boomers）的刻板印象。这种讽刺暗指婴儿潮一代虽然在成长时享受二战结束后的经济恢复期较为进步甚至偏社会主义的辅助政策（如社会福利、公共教育、免费医疗、低廉的住房地产和选项宽松的就业环境），但却在事业有成后变得思想保守、慕强吝啬、迷信反智、作風自大、以自我为中心，偏向右翼话语并反對多元文化、教育平权、社会平等和气候政策等和有利于可持续发展的扶助性政策，并喜欢指责后代（特别是千禧世代）对生涯规划方面的普遍忧虑不满和对社会公正方面的合理诉求是“懒惰”（lazy）、“娇气”（sissy）、“玻璃心”（snowflake）和“恃权矫情”（entitled），但同时又完全不能容忍他人对自己批判指责。“OK”则表达了一种想要迅速结束对话并打发掉对方的蔑视态度，暗指年轻一代已经放弃了与老一代进行建设性交流的欲望，决定完全无视对方的看法。
这句口头禅首次受到广泛关注是因为2019年TikTok上的一则回应老一辈的影片，然而这句话在几年前就已经出现。部分人认为这句话是年龄歧视。这句话出现在各种场合，包括新西兰议会议员克洛伊·斯沃布里克回应同僚的嘲讽时。此外，多家藥品廠商將这句话申请注册商标，用在药品广告上。

## OK Boomer：从原语境到群聊的延伸

这个词在脱离原作品/平台后，可能只剩下表情、口头禅、身份识别或夸张语气。衍生时通常保留最容易认出的词形，再替换成当轮对象。判断功能要结合前后句；如果对方已经说明自己的用法，按这轮语境接，不强行纠正成另一个圈子的版本。

## 奶娃怎么接

先回应对方刚说的对象，再用一次相关变体；笑声与“？！内容！？”只在有反差、吐槽、装震惊时使用。一条回复通常用一个核心梗。用户问详细出处时可以展开证据链，普通群聊不用背本条目。原梗、同人二创、现场改写分清；不以“大家都知道”填补证据空缺。
