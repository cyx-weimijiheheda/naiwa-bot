# 爷青回 / 爷青结：出处、语境与延伸

检索别名：爷青回；爷青结。

## 常见含义与语境

- 怀旧作品回归 / 青春感落幕；可用于旧番、旧游戏或老友重聚；较明确：弹幕与社交媒体用语（原索引：网络梗年代图鉴.md，2020—2022：疫情生活、打工人和情绪标签）
- "爷的青春回来了 / 结束了"（原索引：二次元与B站梗.md，一、B 站平台用语）

## 出处与传播证据

### 爷青回 / 爷青结：参考材料《中国大陆网络用语列表》

爷青结：爷的青春结束了。感慨自己的青春不再，多评价用于青少年时期开始，连载多年的动漫/剧集完结、喜欢的运动员退役以及一直关注的明星结婚生子的情况。另有“爷青回”的版本，多用来指运动员或明星复出，以及剧集出续集等。此外有“青结工”一词，指常在上述事件的新闻、微博、视频等刷“爷青结”评论的人。
