## 出处与传播证据

### 雪山救狐狸：参考材料《雪山救狐狸》

雪山救狐狸（或稱雪山救狐）是一系列於2026年初在網際網路上爆紅的人工智慧生成短片及社群媒體迷因。該系列影片最初由中华人民共和国貴州省贵阳市一家經營醬板鴨（一種湖南、貴州一帶常見的醃製滷味鴨肉）的企業製作，旨在宣傳其產品。影片以「反轉劇情」為核心特點，將中國傳統民間故事中常見的「狐狸報恩」情節，反轉為「醬板鴨復仇」，因其荒誕感與強烈的視覺風格在抖音、Threads、Dcard及Instagram等社群平台廣泛流傳。


== 劇情 ==
影片的核心敘事建立於觀眾對傳統文學或民間傳說中「靈狐報恩」的心理預期。典型劇情為一名男子在數年前的雪山上救下了一隻受傷的白狐，並留下了一隻「醬板鴨」給狐狸充飢。多年後，一名身穿白衣或紅黑刺繡俠客服的神祕美女出現，詢問男子：「你是否在雪山救過一隻狐狸？」男子通常會露出微笑，預備迎接報恩的橋段。然而，劇情隨即發生劇烈反轉，女子拔劍或開槍並宣稱：「我不是那隻狐狸，我是那隻醬板鴨，我是來復仇的！」。隨著迷因的演變，出現了大量「二次創作」版本，復仇者的身分被替換成「雪山本身」、「被留下的核彈」、「聖誕老人」等，甚至演變成男子與所有復仇者結親生子等天馬行空的結局。


== 製作背景 ==
該系列影片的創作者為新媒體運營主管艾林俊吉。他任職於中华人民共和国貴州省貴陽市的一家醬板鴨企業，創作初衷是為了在日常社群媒體更新中推廣自家的產品。團隊最初看到一則關於「狐狸報恩」的AI影片，認為劇情過於老套，遂將受贈物「醬板鴨」設定為具有自我意識的復仇者，以產生幽默的反差效果。
影片主要利用AI影片生成工具「極夢」及「小雲雀」製作。首支影片的硬件與生成成本不到人民幣40元，單條影片從發想到製作完成約5小時。製作者特意選擇了1970年代邵氏電影的懷舊武俠風格，利用高飽和度色彩和人造布景感來掩蓋早期AI技術中眼球活動僵硬等缺陷，反而營造出一種「刻意做舊」的藝術美感。


== 影響 ==
根據報導，「雪山救狐狸」系列在極短時間內席捲各大平台，展現了強大的傳播力。截至2026年3月底，在中國大陸社群平台上，「#醬板鴨」標籤的累計播放量已突破50億次，「#雪山救狐狸」相關話題的播放量則超過2.1億次。在微信，該主題的話題指數峰值曾達到1200萬，反映出極高的討論熱度。此流量亦成功轉化為商業收益，原創團隊所屬企業的社群帳號增粉超過5萬，其產品醬板鴨的銷售量提升了約10%至15%，成功將AI創意轉化為實質銷量。


== 評價 ==
這股AI短片熱潮吸引了大量公眾人物參與及網友二創。歌手蔡依林在長沙演唱會期間，拍片模仿該劇情並笑稱自己是「等吃醬板鴨的蔡依林」，引發粉絲熱烈討論。此外，周杰倫、阿信及演員林柏宏等藝人也紛紛透過轉發或在公開活動中提及此梗，使該迷因進一步出圈。除了娛樂層面，部分中华人民共和国政府機構亦借用此敘事框架製作公益宣導片，推廣反詐騙與交通安全資訊。
新華社在專欄文章中指出，此現象展現了「大眾文化正變得越來越『大眾』，不只大家在『看』，更是大家在『創』」，並肯定其將傳統「報恩」敘事、邵氏武俠情懷與香港無厘頭反轉手法，以AI技術創意融合，激活了全民參與的熱情，形成一場網路時代的「新大眾文藝」的繁榮景象。《人民日報》則在評論中表示，「雪山救狐狸」這類現象「雖是『小把戲』，卻不可小覷」，強調它讓「想像正在成為日常，創造正在成為習慣」，是「社會創新創造活力的生動體現」，並將其視為文化繁榮和文明進步的源泉。光明網也在專文分析其爆紅底層邏輯，指出劇情透過「完全不在預期之內」的醬板鴨反轉，成功顛覆傳統敘事框架，成為AI時代大眾文藝的典型案例。
《網路溫度計》分析指出，「雪山救狐狸」迷因爆紅主要在於其劇情「顛覆傳統『善有善報』的預期」。並以無厘頭幽默與復古武俠視覺風格，迅速從中國大陆延燒至台灣，激發網友強烈參與感，網路上已湧現超過3000條衍生作品，內容涵蓋角色替換、道具魔改及情境改編。


== 衍生發展 ==
鑑於「古裝系列」的成功，原創團隊負責人艾林俊吉表示將持續開發相關內容，並著手建立所謂的「醬板鴨宇宙」。後續計畫包括開發以現代生活為背景的新系列短劇，並將前作的古裝元素以不同形式穿插其中，以維持該IP的長線影響力。
