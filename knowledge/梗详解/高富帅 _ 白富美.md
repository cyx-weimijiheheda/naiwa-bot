# 高富帅 / 白富美：出处、语境与延伸

检索别名：高富帅；白富美。

## 常见含义与语境

- 夸张的择偶条件标签；也用于调侃“人生赢家”；较明确：2010 年代初网络热词（原索引：网络梗年代图鉴.md，2011—2013：贴吧、微博、论坛句式扩散）

## 出处与传播证据

### 高富帅 / 白富美：参考材料《中国大陆网络用语列表》

白富美：指皮膚白皙、家境富裕和漂亮的女性。類似的說法有「白瘦美」或「白细美」，指皮肤白皙，身材苗條和漂亮的女性。

总裁/羅总裁：指C朗，褒貶不一。初始原意為諷刺其「總靠裁判」之贬称。但也有球迷因認為其「場上霸氣，外型高富帥」等酷似总裁形象而如此稱呼。

高富帅：指个子高，又有钱，人又帅的男子，与矮穷挫相对。

### 高富帅 / 白富美：参考材料《三高男》

同时在大中华地区，中国大陆有类似的“高富帥”一詞，意為“身材高、財富多、長相帥”；臺灣有近義詞“溫拿”（英文winner的諧音，指成功者、胜利者），代表社会上的「人生勝利組」；新加坡称为“5C”，表示拥有金钱、汽车、信用卡、公寓和俱乐部会员的高尚阶级。

### 高富帅 / 白富美：参考材料《屌丝》

屌丝，是自2012年初開始從中国大陆興起的流行詞，字面意思為男性的阴毛，後引申為「人生失败者」、「人生输家」、「單身漢」、「愛情輸家」、「窮小子」、「LOSER」的泛稱。義近於台灣網路用語魯蛇或中國大陸的擼瑟，也義近於香港網路用語廢青、毒男、哥布林、肥矮毒杘窮。與高富帥相對。2015年，人民网舆情研究室发布的网络低俗粗鄙语言的报告显示，“尼玛”、“屌丝”和“逗比”位列前三。
