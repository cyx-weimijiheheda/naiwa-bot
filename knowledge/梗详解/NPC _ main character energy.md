# NPC / main character energy：出处、语境与延伸

检索别名：NPC；main character energy。

## 常见含义与语境

- 把人比作背景角色 / 主角气场；容易把真人标签化，宜用于自嘲或作品角色；游戏与短视频表达扩展（原索引：网络梗年代图鉴.md，英语互联网与跨平台格式（2011—2026））

## 出处与传播证据

### NPC / main character energy：参考材料《非玩家角色》

非玩家角色或稱非操控角色（英語：Non-Player Character，縮寫：NPC），是指角色扮演遊戲中非玩家控制的角色。

NPC是遊戲背景中，非主角（狭义上来说还要求非敌人）的陪襯人物。玩家藉由他們與遊戲互動。在桌上角色扮演遊戲裡，NPC是由遊戲主持者操縱，而在電腦角色扮演遊戲裡，則是由程序預設的脚本來決定NPC的反應，由遊戲的人工智能做出控制。部分NPC有時可變成可操控角色。

1990年代的台灣，NPC一詞還未普及時，有些玩家會把NPC說成是「電腦角色」。

## NPC / main character energy：从原语境到群聊的延伸

常被用作情绪压缩：同一句可能是轻度抱怨，也可能是在说真实困难。自称使用比给别人贴标签更稳妥；接话时优先点中本轮处境，给出一个轻反转或具体帮忙。衍生表达常把情绪人格化，或把小困境包装成宏大危机。
