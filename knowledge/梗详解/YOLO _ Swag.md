# YOLO / Swag：出处、语境与延伸

检索别名：YOLO；Swag。

## 常见含义与语境

- “只活一次”的冲动宣言 / 炫酷人设；当下多用于复古反讽；2011—13 年主流流行语；不要装作仍很潮（原索引：网络梗年代图鉴.md，英语互联网与跨平台格式（2011—2026））

## 出处与传播证据

### YOLO / Swag：参考材料《YOLO》

YOLO是英文You Only Live Once（你只活一次）的首字母縮略字。如同carpe diem（活在當下）和memento mori（勿忘你終有一死）兩句拉丁文俗語一樣，YOLO鼓勵人們即使冒著生命危險也要享受人生，而這一句話也常常用在青少年的對話和音樂當中。加拿大饒舌歌手德雷克的〈The Motto〉使此句普及於網路中。

### YOLO / Swag：参考材料《SWAG》

SWAG，台灣影音串流平台，於2016年8月由黃立成創辦，前身為17LIVE旗下的副品牌，專做網紅直播，經營粉絲經濟；但隨著平台表演尺度逐漸走向成人內容，於2017年5月由原任產品PM的Sam Liu接手為獨立品牌並擔任新品牌的CEO。
SWAG為亞洲最大成人創作平台，主打「與成人偶像零距離」，以情色版的限時動態和自製AV在亞洲市場走紅，用戶可以換取鑽石作為交易貨幣，並消費鑽石觀看直播、送禮、影音解鎖與私訊聊天。而創作者亦可藉由直播表演、上傳影音內容及與粉絲互動獲得收入報酬。

## YOLO / Swag：从原语境到群聊的延伸

有明显评价或挑衅功能：同好互损时可制造节目效果，陌生人或争执中会加重敌意。衍生版常省略主语、提高语气、重复关键词。奶娃应针对当前行为/逻辑补一个具体笑点，别用标签替代论证，也别在对方认真解释时只复读“急了”。

## 奶娃怎么接

先回应对方刚说的对象，再用一次相关变体；笑声与“？！内容！？”只在有反差、吐槽、装震惊时使用。一条回复通常用一个核心梗。用户问详细出处时可以展开证据链，普通群聊不用背本条目。原梗、同人二创、现场改写分清；不以“大家都知道”填补证据空缺。
