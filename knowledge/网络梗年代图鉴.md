# 网络梗年代图鉴（2011—2026）

给群聊检索用的年代索引。年份表示大致出圈期，不等于最早出现年份；很多词在贴吧、论坛、短视频和群聊之间反复改写。一个词也可能有多个来源。表中标注“来源较明确”的才适合讲出处；其余按语境理解，不要把考据猜测讲成定论。

## 2011—2013：贴吧、微博、论坛句式扩散

| 梗/词 | 常见意思、功能与用法 | 来源把握 |
|---|---|---|
| 元芳，你怎么看 | 发生离谱事后假装征求权威意见；反讽或抛话题 | 较明确：电视剧《神探狄仁杰》台词经微博传播 |
| 不明觉厉 | “虽然不懂但觉得厉害”的自嘲式赞叹；也可拆成认真追问 | 较明确：早期论坛缩写句式 |
| 十动然拒 | “十分感动，然后拒绝”的压缩叙事，常用于表白失败或反转 | 较明确：2012 年网络新闻传播后定型 |
| 人艰不拆 | “人生已经很艰难，有些事就别拆穿”；委婉自嘲 | 较明确：歌曲歌词经网络缩写流行 |
| 喜大普奔 | “喜闻乐见、大快人心、普天同庆、奔走相告”的戏谑拼接 | 较明确：论坛缩略语 |
| 累觉不爱 | “累了，感觉不会再爱了”；夸张表达疲惫、失望 | 较明确：贴吧句式 |
| 细思恐极 | “仔细想想有点可怕”；常用于反转或脑洞 | 较明确：网络缩写句式 |
| 火钳刘明 | “火前留名”的谐音，抢在热帖前排留痕 | 较明确：贴吧回帖语 |
| 男默女泪 | 夸张说法，表示某事令男性沉默、女性落泪；如今常反讽标题党 | 较明确：网络标题句式 |
| 说闹觉余 | “说着说着闹起来，觉得自己多余”；冷场/围观自嘲 | 较明确：网络缩写句式 |
| 给跪了 | 表示服气、震惊，也可阴阳怪气地表示“行行行你厉害” | 较明确：论坛口语 |
| 躺着也中枪 | 没参与却被波及；无辜背锅的自嘲 | 较明确：影视台词传播后成为常用语 |
| 高富帅 / 白富美 | 夸张的择偶条件标签；也用于调侃“人生赢家” | 较明确：2010 年代初网络热词 |
| 中国式过马路 | 对集体跟风现象的概括；涉及现实交通时不当作无害笑料 | 较明确：2012 年媒体讨论后走红 |
| 甄嬛体 | 模仿宫斗剧文绉绉、绕弯子的说话方式；适合改写成办公室/作业版 | 较明确：电视剧《甄嬛传》衍生 |
| 江南 Style / 骑马舞 | 洗脑歌舞的全球化模仿梗；用于形容突然魔性循环 | 较明确：PSY 音乐视频 |
| 舌尖上的 XX | 把地方、美食、日常小事包装成纪录片旁白 | 较明确：纪录片《舌尖上的中国》标题模板 |

## 2014—2016：微博热搜、综艺和表情包接管

| 梗/词 | 常见意思、功能与用法 | 来源把握 |
|---|---|---|
| 也是蛮拼的 | 用来夸人努力，也能讽刺忙得很认真但方向不对 | 较明确：综艺《爸爸去哪儿》传播 |
| 且行且珍惜 | 对关系、机会或某段时光的戏谑式珍惜；常故意用在小事上 | 较明确：2014 年娱乐新闻热词 |
| 画面太美我不敢看 | 看到尴尬、辣眼或过于刺激的场面时夸张回避 | 较明确：蔡依林歌曲/媒体标题传播 |
| 我也是醉了 | 无语、哭笑不得；语气可轻可重 | 较明确：游戏/直播与网络聊天扩散，单一源头说法不一 |
| 重要的事情说三遍 | 重复强调；故意把小事说成重大公告也好笑 | 较明确：网络句式 |
| 主要看气质 | 对“内在更重要”的反讽式包装；常配随意照片 | 较明确：2015 年网络话题 |
| 吓死宝宝了 | 装可爱地表示害怕或被吓到；也常用于反讽 | 较明确：2015 年热词盘点 |
| 内心几乎是崩溃的 | 表面镇定、内心慌乱；适合考试、工作、社交翻车 | 较明确：网络采访语句传播 |
| 世界那么大，我想去看看 | 想辞职、逃离日常或去旅行；也可对小逃跑愿望过度抒情 | 较明确：辞职信新闻 |
| 一言不合就 XX | 表示某人动不动就做某事；槽点常在后半句故意升级 | 较明确：2015—16 网络句式 |
| 洪荒之力 | 把爆发式努力说得很宏大；现在常用于“我已用尽最后电量” | 较明确：傅园慧采访在 2016 年走红 |
| 吃瓜群众 | 不参与争论、只围观的人；也可用作自我定位 | 较明确：2016 年广泛传播的网络称呼 |
| 葛优躺 | 以瘫坐姿势表达疲惫、摆烂或拒绝营业 | 较明确：电视剧画面二创，2016 年走红 |
| 蓝瘦香菇 | 把“难受，想哭”说成谐音腔；主要是模仿口音的旧梗 | 较明确：2016 年视频传播；模仿真人口音要看关系 |
| 友谊的小船说翻就翻 | 形容友情经不起一点小事；如今常作轻量吐槽 | 较明确：漫画/社交媒体传播 |
| 小目标，先挣一个亿 | 把宏大目标说得像随手小事；适合吐槽计划与现实的落差 | 较明确：2016 年采访片段 |
| 你咋不上天 | 对夸张、自信或要求过高的吐槽；别对认真求助者用 | 较明确：网络口语 |
| 老司机 / 老司机带带我 | 熟门熟路的人带路；在低俗语境可有双关，默认按普通“老手”理解 | 来源多，语境依赖 |
| 皮皮虾我们走 | 组队撤退、转场或起哄；也可套用成“XX 我们走” | 较明确：游戏直播/表情包传播，早期来源有不同说法 |

## 2017—2019：短视频、弹幕、抽象与反讽

| 梗/词 | 常见意思、功能与用法 | 来源把握 |
|---|---|---|
| 扎心了，老铁 | 被说中痛点；能真共情也能自嘲 | 较明确：直播与社交平台口语 |
| 你的良心不会痛吗 | 对双标、偏心或坑人行为发问；适合轻度控诉 | 较明确：网络表情包句式 |
| 我劝你善良 | 夸张制止对方继续搞事；也可反讽自己没资格劝 | 较明确：影视对白传播 |
| 社会人 / 小猪佩奇身上纹 | 把幼稚装酷、江湖气做成反差笑点；不要拿真实纹身或身份做攻击 | 较明确：2018 年短视频/动画形象传播 |
| 皮一下很开心 | 调皮一下就满足；适合承认自己故意捣乱 | 较明确：2018 年流行语盘点 |
| 确认过眼神 | 看一个动作/表情就认出同类；常改成“确认过眼神，是……” | 较明确：歌词与广告传播后成为模板 |
| C 位出道 | 把某人/某物说成全场中心；可认真夸也可反讽抢戏 | 较明确：偶像选秀语境 |
| 盘它 | 把“收拾、安排、搞定”说得夸张；本义和语气依上下文变化 | 较明确：相声节目传播 |
| 真香 | 从拒绝到接受的态度反转；也可用于预判自己会打脸 | 较明确：王境泽节目片段二创 |
| 雨女无瓜 | “与你无关”的谐音变体；多用于装傻式挡回去 | 较明确：电视剧《巴啦啦小魔仙》片段二创 |
| 996 / 007 | 对加班制度的概括；用于吐槽劳动强度，别把过劳当励志 | 较明确：劳动议题词语 |
| 我太难了 | 轻量卖惨、表达压力；强度需要看聊天气氛 | 较明确：主播口头表达在 2019 年走红 |
| 硬核 | 很强、很直接或技术含量高；也可形容朴素粗暴的解决方案 | 较明确：游戏/音乐语境扩展 |
| 柠檬精 | 对他人羡慕嫉妒时的自嘲；比直接酸人更软化语气 | 较明确：社交媒体称呼 |
| 我酸了 | 表示羡慕；可真诚祝贺后自嘲一句 | 较明确：网络口语 |
| 脑壳疼 | 对麻烦或信息量过载的拟态抱怨 | 较明确：方言词跨平台传播 |
| 鸡你太美 / 蔡徐坤篮球梗 | 围绕歌曲和篮球视频的恶搞二创；极易滑向针对真人的刷屏/霸凌，机器人不主动复读羞辱版本 | 出处较明确，使用慎重 |
| 真下头 / 上头 | 对人或事感到反感 / 沉迷；是情绪描述，不是客观诊断 | 较明确：2019 年前后社交平台热词 |

| 电子榨菜 | 吃饭时配着看的轻松视频/剧；“下饭内容”的新叫法 | 较明确：2022 年网络流行语 |
| 刘畊宏女孩 / 王心凌男孩 | 因直播健身或怀旧舞台走红的跟练/粉丝称呼 | 较明确：2022 年直播与综艺热点 |
| 尊嘟假嘟 | “真的假的”的卖萌谐音；常故意用甜腻腔增加反差 | 较明确：2023 前后短视频传播 |

## 2023—2026：搭子、抽象短剧、AI 与反差表达

| 梗/词 | 常见意思、功能与用法 | 来源把握 |
|---|---|---|
| 显眼包 | 因行为/装扮格外突出的人；可夸可损，先看对方是否接受调侃 | 较明确：2023 年年度流行语之一 |
| 搭子 | 只在某项活动上合拍的伙伴，如饭搭子、游戏搭子；强调低负担关系 | 较明确：2023 年年度流行语之一 |

| 质疑、理解、成为 | 描述从不理解到亲自加入的态度变化；适合自嘲“我也逃不过” | 较明确：2023 年网络句式及年度流行语收录 |
| 情绪价值 | 让人感到被支持、被理解或相处舒服的互动体验；滥用会显得像在给关系打 KPI | 较明确：2023 年流行语 |
| 特种兵式旅游 | 短时间、高强度打卡式旅行；适合吐槽行程排得像拉练 | 较明确：2023 年网络热词 |

## 机器人使用规则

- 先判断这句话在本轮承担什么功能（赞同、拒绝、自嘲、夸张、阴阳、求助），再挑梗；同一个词的年代和语气都可能变。
- 被直接问出处时，优先说“常见说法是……，但来源版本不止一个”；只把明确有记录的内容说成确定来源。
- 群友正在认真求助、表达痛苦或遇到现实伤害时，先回应问题本身，不要把情绪词当笑点。
- 一次回应挑 0—2 个相关梗即可；旧梗可以当复古笑点，不要冒充新梗。
- 梗的意义可能因平台、地域和圈层不同而变化。贴吧内部黑话尤其不要不看上下文就外推到普通群聊。
- 对灾难、伤亡、疾病、残障、未成年人和现实受害者，不拿当事人做梗；梗可对准荒唐行为与制度，不对准受害者身份。
