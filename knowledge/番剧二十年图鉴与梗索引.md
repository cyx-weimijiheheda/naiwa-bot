# 番剧二十年图鉴与梗索引（2006—2026）

本表是给聊天模型检索的“作品识别卡”，涵盖日本 TV/网络动画、剧场作品和国产动画。年份通常指首播年；系列作品只列最有代表性的入口，不等于完整观看顺序。类型标签是便于检索的概括，作品可能跨多个类型。梗条目写的是观众常见的二创/讨论方向，不是剧情复述。动画事实与流行梗都可能因地区、平台、译名和时间变化而异。

## 怎么使用这份目录

- 先认作品、年代、类型和群友提到的角色/短语，再决定要不要接梗；不确定就问“你说的是哪一版/哪一集”。
- 不要把作品的高能转折、角色生死、结局、CP 结果当作无剧透闲聊。有人说“没看过”时，只给无剧透梗概。
- 下面“常见梗点”尽量是识别线索，不是要机器人逐字复读台词。台词、弹幕、空耳存在字幕版本差异。
- 作品名有时同时指漫画、小说、游戏或动画；回答“哪来的”时标清媒介和年份，不要把原作年份说成动画年份。
- 番剧“出圈/霸权/神作”属于特定社群或平台的评价，不是客观奖项。可以说“常被讨论为……”，不要说“公认第一”。

## 角色梗与梗功能速查

| 角色/词 | 从作品中识别的功能 | 正确使用边界 |
|---|---|---|
| 丘比 / “签约” | 看似可爱、实则交易条件不对等；吐槽诱人合同 | 不要把现实受害者被诱骗的经历当玩笑 |
| 阿尼亚 / waku waku | 小孩式期待、表情泄露心声 | 角色是未成年人；不用来做性化内容 |
| 波奇 / 社恐 | 社交焦虑被夸张可视化、想加入又想逃 | 现实焦虑应认真回应，不能默认对方“只是波奇” |
| 芙莉莲 / 辛美尔 | 后知后觉、长时间跨度、回忆补课 | 适合温柔反转，别硬转长篇哲学独白 |
| 五条悟 / 领域展开 | “切换到最强状态/启动专属领域”的夸张动作 | 网络二创和剧情事实分开；不要无剧透群里讲角色战局 |
| 齐木楠雄 | 表面平静、内心吐槽、想安静却被事件追着跑 | 适合轻吐槽，不要把社交退缩说成超能力 |
| 埼玉 | 实力过强但生活很普通、兴趣被日常打断 | 不拿秃头/外貌攻击群友 |
| 阿库娅 | 高调、添乱、却仍是团队成员 | 只用于虚构角色/自嘲，不拿信仰或真实能力问题嘲讽 |
| 书记舞 / 藤原千花 | 洗脑舞蹈、突然抢走注意力 | 识别为《辉夜大小姐》动画二创，不混成原作台词 |
| 夏目 / 猫咪老师 | 温柔、妖怪、人类与非人相遇 | 适合温和接梗，别把失去/孤独一律变成笑点 |
| 银魂 | 一本正经地胡说、打破第四面墙 | 大量梗依赖原文化上下文，不确定就只说“银魂式吐槽” |
| JOJO | 夸张姿势、替身对决、梗中梗 | 不是所有夸张姿势都是 JOJO 原梗；原作部数/人物容易认错 |

- [Netflix 动漫分类](https://www.netflix.com/browse/genre/7424) 与 [Crunchyroll](https://www.crunchyroll.com/series)：流媒体上架范围和地区可用性入口；目录会因授权动态变化。
- [中国国家广播电视总局：年度优秀动画片名单](https://www.nrta.gov.cn/)，用于查国产动画的官方评选记录；“优秀名单”不能代表完整作品目录。

## 新番/热梗更新规范

2026 年仍在播出的作品、剧场版上映日、续作宣布和流媒体地区版权必须联网核对。建议记录“检索日期 + 官方/平台页面 + 讨论社区样本”，并把“播出事实”“平台排名”“社群玩梗”分成不同字段。老梗整理不等于仍流行；群里没人用时，不要为展示知识强塞作品名。
